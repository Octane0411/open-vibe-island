Open Island · Halo Theme

Halo — Intelligence

A true-black OLED void that fuses with the notch — the overlay reads as the notch itself growing. No fills, no cards, no vibrancy: content floats in the black, structure comes from type and hairlines. The only chrome is a 1.5px living edge-light — the Apple-Intelligence glow, engineered into a monitoring instrument. The edge is the state channel: 95% of the time it's a bare hairline; when something needs you, the light condenses, warms, and travels to the exact spot. Nothing moves but light.
