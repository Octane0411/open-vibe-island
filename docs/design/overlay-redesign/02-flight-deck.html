Flight Deck 2.0 · Glass Cockpit

Not aviation cosplay — aviation-grade information design. One dark instrument panel where light is spent only on meaning: a lamp lights when, and only when, something is true. Attention is a MASTER ALARM — permission is a red WARNING that blocks, a question is an amber CAUTION that waits. Every value is a tabular readout; every state pairs a lamp with a placard, so nothing depends on colour alone.
